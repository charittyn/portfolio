# Charity Nkonyedi Portfolio — Production Build

This folder is the cleaned, production-ready static version of the portfolio.

## Deployment

There is no build step. Upload the contents of this folder directly to the public web root, or publish it as the root of the GitHub Pages repository.

The included `CNAME` points to `www.charittyn.com`.

## Important configuration

The contact form uses the Web3Forms access key that was already present in the original portfolio. Before production launch, log in to the Web3Forms account and restrict/verify the permitted domain if that option is available in the account.

## Content evidence

The rebuild deliberately does not fabricate campaign screenshots, analytics dashboards, client logos, testimonials or performance metrics. Case studies use only the project information already present in the supplied portfolio, with the internally inconsistent `20% ROAS` statement omitted.

If original screenshots, campaign reports, client logos or a CV are supplied later, they can be added as stronger supporting proof without changing the site architecture.
